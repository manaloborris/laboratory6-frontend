# Stockroom Frontend

React/Vite client for the LavaLust product API. It never connects to MySQL directly.

1. Copy `.env.example` to `.env` and set `VITE_API_URL` to the LavaLust API origin.
2. Run `npm install` and `npm run dev` for local development.
3. Run `npm run build` to create the Render Static Site output in `dist/`.

See [`../LavaLust/LAB6_SETUP.md`](../LavaLust/LAB6_SETUP.md) for Aiven, API, and Render setup.
